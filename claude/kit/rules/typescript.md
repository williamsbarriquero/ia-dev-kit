# Padrões TypeScript

## Ativação

Ao editar arquivos `.ts` / `.tsx`:

- **UI (componentes, hooks, `.tsx`)**: leia **`frontend-mastery`** (`.claude/skills/frontend-mastery/SKILL.md`) → `.claude/knowledge/stacks/frontend.md`
- **Backend Node**: leia **`node-mastery`** (`.claude/skills/node-mastery/SKILL.md`) → `.claude/knowledge/stacks/node.md`

Conforme rule `stack-baseline` → seção Node.js / TypeScript.
